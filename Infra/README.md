# Infra

This directory contains deployment guidance and environment configuration for Railway.

## Deployment

- Use Railway to deploy the backend service.
- Connect your Supabase database and store environment variables securely in Railway.
- The frontend can be deployed as a static site on Railway or another static hosting provider.

## Environment variables

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `PORT`
