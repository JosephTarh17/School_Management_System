## 2. Core Components (Vue + Tailwind)

### Button.vue
```vue
<template>
  <button 
    :class="[
      'px-4 py-2 rounded-lg font-medium transition-all duration-200 active:scale-95 flex items-center justify-center gap-2',
      variant === 'primary' ? 'bg-primary-600 hover:bg-primary-700 text-white shadow-sm' : '',
      variant === 'secondary' ? 'bg-white border border-gray-300 text-gray-700 hover:bg-gray-50 shadow-sm' : '',
      variant === 'ghost' ? 'text-primary-600 hover:bg-primary-50' : '',
      fullWidth ? 'w-full' : ''
    ]"
    @click="$emit('click')"
  >
    <slot name="icon-left" />
    <slot />
    <slot name="icon-right" />
  </button>
</template>

<script setup>
defineProps({
  variant: { type: String, default: 'primary' },
  fullWidth: { type: Boolean, default: false }
})
defineEmits(['click'])
</script>
```

### InputField.vue
```vue
<template>
  <div class="mb-4">
    <label :for="id" class="block mb-2 text-sm font-medium text-gray-900">{{ label }}</label>
    <div class="relative">
      <span v-if="icon" class="absolute inset-y-0 left-0 pl-3 flex items-center text-gray-400">
        <i class="material-icons text-sm">{{ icon }}</i>
      </span>
      <input
        :id="id"
        :type="type"
        :value="modelValue"
        @input="$emit('update:modelValue', $event.target.value)"
        :placeholder="placeholder"
        :required="required"
        :class="[
          'w-full border border-gray-300 rounded-lg focus:ring-primary-500 focus:border-primary-500 p-2.5 transition-shadow',
          icon ? 'pl-10' : '',
          error ? 'border-error-500 focus:ring-error-500' : ''
        ]"
      />
    </div>
    <p v-if="error" class="mt-1 text-xs text-error-600">{{ error }}</p>
    <p v-if="hint && !error" class="mt-1 text-xs text-gray-500">{{ hint }}</p>
  </div>
</template>

<script setup>
defineProps({
  id: String,
  label: String,
  type: { type: String, default: 'text' },
  placeholder: String,
  modelValue: [String, Number],
  icon: String,
  error: String,
  hint: String,
  required: Boolean
})
defineEmits(['update:modelValue'])
</script>
```

### Card.vue

```vue
<template>

    <div v-if="$slots.header" class="px-6 py-4 border-b border-gray-100 bg-gray-50/50">

    <div v-if="$slots.footer" class="px-6 py-4 border-t border-gray-100 bg-gray-50/50">
      <slot name="footer" />
    </div>
  </div>

```

### StatusBadge.vue
```vue
<template>
  <span 
    :class="[
      'px-2.5 py-0.5 rounded-full text-xs font-semibold',
      statusClass
    ]"
  >
    <slot />
  </span>
</template>

<script setup>
import { computed } from 'vue'
const props = defineProps(['type'])

const statusClass = computed(() => {
  const map = {
    'Present': 'bg-green-100 text-green-800',
    'Absent': 'bg-red-100 text-red-800',
    'Late': 'bg-yellow-100 text-yellow-800',
    'Excused': 'bg-blue-100 text-blue-800',
    'Active': 'bg-primary-100 text-primary-800',
    'Pending': 'bg-gray-100 text-gray-800'
  }
  return map[props.type] || map['Pending']
})
</script>
```

## 4. Implementation Notes for VS Code
1. **Utility First:** Use the Tailwind classes provided above to build out the layout shells (`Layout.vue`).
2. **Iconography:** The designs use **Material Icons**. Ensure you include the Material Icons font in your `index.html`.
3. **Responsive Design:** Use Tailwind's `lg:flex` and `hidden` classes to handle the sidebar visibility on mobile vs. desktop.
4. **State Management:** Use Vue's `reactive` or `ref` to handle form states before sending them to your backend.
