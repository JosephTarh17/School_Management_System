# SMS Vue.js Implementation Guide

This document provides the Vue component structure, props, and routing mapping for the School Management System (SMS) based on the "Institutional Excellence" design system.

## 1. Core Component Library

### Button.vue
```vue
<template>
  <button 
    :class="[
      'px-4 py-2 rounded-lg font-medium transition-colors',
      variant === 'primary' ? 'bg-primary-600 hover:bg-primary-700 text-white' : '',
      variant === 'secondary' ? 'bg-white border border-gray-300 text-gray-700 hover:bg-gray-50' : '',
      variant === 'ghost' ? 'text-primary-600 hover:bg-primary-50' : ''
    ]"
    @click="$emit('click')"
  >
    <slot />
  </button>
</template>

<script setup>
defineProps({
  variant: { type: String, default: 'primary' }
})
defineEmits(['click'])
</script>
```

### InputField.vue
```vue
<template>
  <div class="mb-4">
    <label :for="id" class="block mb-2 text-sm font-medium text-gray-900">{{ label }}</label>
    <div class="relative">
      <span v-if="icon" class="absolute inset-y-0 left-0 pl-3 flex items-center text-gray-400">
        <i :class="['material-icons text-sm']">{{ icon }}</i>
      </span>
      <input
        :id="id"
        :type="type"
        :value="modelValue"
        @input="$emit('update:modelValue', $event.target.value)"
        :placeholder="placeholder"
        :class="[
          'w-full border border-gray-300 rounded-lg focus:ring-primary-500 focus:border-primary-500 p-2.5',
          icon ? 'pl-10' : ''
        ]"
      />
    </div>
    <p v-if="error" class="mt-1 text-sm text-error-600">{{ error }}</p>
  </div>
</template>

<script setup>
defineProps(['id', 'label', 'type', 'placeholder', 'modelValue', 'icon', 'error'])
defineEmits(['update:modelValue'])
</script>
```

## 2. Page Components & Routing

### 1. Login (SMS - Login Page)
*   **Route:** `/login`
*   **Form Handling:**
    *   `email`: `type="email"`, required
    *   `password`: `type="password"`, required
*   **Actions:** `signIn()` -> POST `/auth/login`

### 2. Sign Up (SMS - Sign Up Page)
*   **Route:** `/register`
*   **Form Handling:**
    *   `fullName`: `type="text"`
    *   `email`: `type="email"`
    *   `password`: `type="password"` (min-length: 8)
    *   `role`: `Select` (`Student`, `Teacher`, `Admin`)
*   **Actions:** `createAccount()` -> POST `/auth/register`

### 3. Dashboard (SMS - Dashboard)
*   **Route:** `/dashboard`
*   **Data Props:**
    *   `metrics`: Object containing `totalStudents`, `attendanceRate`, `activeCourses`, `pendingInvoices`.
    *   `recentActivity`: Array of events.
    *   `upcomingSchedule`: Array of sessions for current day.
*   **API Sources:** GET `/dashboard/summary`, GET `/dashboard/activity`

### 4. Attendance Management (SMS - Attendance Management)
*   **Route:** `/attendance`
*   **Filters:** `studentName`, `date` (mm/dd/yyyy), `courseSelection`.
*   **Fields per Row:**
    *   `status`: Enum `[Present, Absent, Late, Excused]`
*   **Actions:** `refreshData()`, `exportReport()`, `updateStatus(id)`

### 5. Course Catalog (SMS - Course Catalog)
*   **Route:** `/courses`
*   **Card Props:** `courseCode`, `courseName`, `department`, `term`, `creditUnits`.
*   **Actions:** `addNewCourse()`, `viewDetails(id)`, `manageSessions(id)`

### 6. Assessments (SMS - Assessments)
*   **Route:** `/assessments`
*   **Fields:** `assessmentTitle`, `courseId`, `dueDate`, `weight`, `type` (Quiz/Exam/Assignment).
*   **Actions:** `createAssessment()`, `gradeSubmission(id)`

### 7. Financial Records (SMS - Financial Records)
*   **Route:** `/finance`
*   **Metrics:** `totalCollected`, `pendingReceivables`, `overdueAmount`.
*   **Table Columns:** `invoiceId`, `studentName`, `category`, `amount`, `status`, `dueDate`.

---

## 3. Global Layout (Layout.vue)
*   **Sidebar:** Navigates between the routes above.
*   **TopBar:** Search bar functionality, notification feed toggle, user profile dropdown.
